# Overview

This Repo serves as the API for "Nashville Rides and Tours", a capstone project for NSS.

This project uses the Nashville-Tours Client for the frontend which can be accessed at: https://github.com/jamesfreeman114/Nashville-Tours-Client


## Getting Started 

- [ ] Clone this repository onto your machine
- [ ] In the project's directory on your terminal run `pipenv install` to create your virtual environment
- [ ] Then run `pipenv shell` to launch the virtual environment
- [ ] Select the interpreter for the virtual environment
- [ ] In your project's directory inside the terminal run `./seed_database.sh` to load fixture data.
- [ ] In your project's directory inside the terminal run `python3 manage.py runserver` to start the server
- [ ] Start the client
